{# Fixed 4-action quick-tap toolbar above the /creator/bot composer. These are the ONLY chips shown; they replaced the context-driven suggestion strip. Each button has a compact visible label, with the full action name on aria-label for screen readers. Every icon carries a data-bot-prompt with the exact chat text it starts. bot.js's delegated composer click handler (see bot.js:395-405) picks up any [data-bot-prompt] tap, sets the textarea value, and calls composer.requestSubmit() — the same submission path a hand-typed message takes. data-chip-submit="1" is kept for parity with the inline-in-chat chip handler which also looks for it. The four actions are deliberately generic manager verbs so babyg can interpret them against live user context on the model side — no new backend behavior is needed to make them work. #}
